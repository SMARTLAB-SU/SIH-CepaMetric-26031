# Dataset

The raw dataset used to train and validate this project is not included in this repository. This repository contains no raw onion images, annotations, patient information, or dataset archive.

The supplied Xception training notebook references the Kaggle dataset [Onion Dataset Combined](https://www.kaggle.com/datasets/yashraneja2/onion-dataset-combined) with four classes: `molded`, `normal`, `rotten`, and `sprouted`.

Class counts, train/validation/test statistics, augmentation totals, and the final dataset license were not stored in the supplied project. Confirm those details from the authoritative dataset version before reproducing training or publishing results.

Dataset access is controlled by the dataset owner and Kaggle under the applicable license and platform terms. Do not redistribute dataset files through this repository unless permission is confirmed.
